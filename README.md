# MG-MTTA

Official project page for **Majorization-Guided Test-Time Adaptation for Vision-Language Models under Modality-Specific Shift**, accepted by ACM Multimedia 2026.

[Project Page](https://mg-mtta.github.io/) · [Paper](https://doi.org/10.1145/3767308.3836429) · [Code](https://github.com/cnLixianChen/Majorization-Guided-Multimodal-TTA)

## Homepage

A buildless, responsive research page with a subtle landscape background, capsule controls, a method overview and interactive benchmark comparisons. No backend, installation or build step is needed.

Open `index.html` directly for a local preview, or serve this directory with `python -m http.server 8000`.

For GitHub Pages, keep `index.html`, `styles.css`, `script.js`, `benchmark.js`, `.nojekyll` and `assets/` at the repository root. Existing Pages settings can stay as configured.

All benchmark numbers are from [paper v4](https://arxiv.org/html/2604.24602v4). WMC diagnostics and the L5 ablation are labeled separately from the L1–L4 main benchmark. The complete comparison table preserves the results of all reported methods.

Local fonts and their licenses are included. Background provenance and its generation prompt are recorded in [assets/README.md](assets/README.md).
