# MG-MTTA Project Page

Static CVPR-style project page for:

**Majorization-Guided Test-Time Adaptation for Vision-Language Models under Modality-Specific Shift**

## Files

- `index.html`
- `styles.css`
- `script.js`
- `assets/fig1.svg`

## Deploy with GitHub Pages

1. Copy all files to the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the default branch and `/ (root)`.
5. Save.
