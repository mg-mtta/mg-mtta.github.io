# Homepage assets

- `fig1.webp` and `fig1.svg`: original motivation figure retained from the project repository.
- `hero-landscape.webp`: original decorative background generated with the built-in imagegen tool for this redesign. It is not experimental evidence. Optimized WebP, 1672 × 941 pixels, about 91 KB.
- `favicon.svg`: vector mark for this project page.
- `fonts/`: self-hosted Manrope (page typography), Inter (fallback) and Source Serif 4 (mathematical notation), obtained from Google Fonts and converted to WOFF2 without changing the font design. The corresponding SIL Open Font License files are included.

## Background generation prompt

Use case: photorealistic-natural. Asset type: wide photographic background for an academic vision-language machine learning paper website. Primary request: an elegant, very pale misty forest landscape with layers of distant hills, atmospheric soft morning fog, tranquil muted sage green vegetation at the lower left and lower right edges, ivory overcast sky. Composition: panoramic 16:9, large quiet luminous negative space across the central 65 percent and upper center for overlaid dark text; delicate organic silhouettes mostly at far edges and bottom quarter. Color palette: very light warm ivory, mist gray, sage green, subdued forest green. Mood: calm, refined, subtle, scholarly, natural editorial landscape photograph with soft texture. Constraints: no people, animals, buildings, text, logo, watermark, high contrast features, saturated colors, neon, or diagrams. This is a finished background asset, not a screenshot or webpage mockup.

The hero uses CSS overlays and a downward fade. Adjust the gradient opacity in `.hero-landscape` in styles.css to make it lighter or stronger.
